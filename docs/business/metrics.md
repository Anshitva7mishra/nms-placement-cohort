# Success Metrics

| Metric | Why it matters |
|---|---|
| Registrations per track | Understand demand |
| Attendance and assignment rate | Check engagement |
| Baseline vs final score | Measure actual improvement |
| Mock interview rating growth | Measure interview readiness |
| Interviews attended and offers | Track outcomes without promising them |
| Satisfaction and referral rate | Word-of-mouth strength |

## Funnel Metrics

| Stage | Metric |
|---|---|
| Awareness | Content reach, followers |
| Interest | Free session and resume review sign-ups |
| Trial | Demo mock interview attendance |
| Conversion | Registration rate from demo |
| Retention | Weekly attendance, completion rate |
| Advocacy | Referrals, testimonials |

## Measurement Rules

1. Use the same baseline test and final assessment format for all students in a track
2. Use a standard mock interview rubric across mentors
3. Report outcomes as tracked data, not as promises
4. Collect consent before using any student result publicly
5. Review metrics weekly in the Sunday review

## Review Cadence

| Frequency | Review |
|---|---|
| Weekly | Attendance, assignments, mini test scores |
| Mid-cohort | Feedback survey and mentor review |
| End of cohort | Baseline vs final, outcomes, satisfaction |
