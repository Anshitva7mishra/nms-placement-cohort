# Decision Log

Decisions that change scope, pricing, tracks or policy are recorded here as Architecture Decision Records (ADRs), so the team always knows what was decided and why.

## How to Add a Decision

1. Copy [ADR-TEMPLATE.md](ADR-TEMPLATE.md)
2. Name it with the next number, for example `0002-target-year.md`
3. Fill in the context, options and decision
4. Link it from your pull request and add a row below
