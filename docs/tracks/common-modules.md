# Common Modules (All Tracks)

| Module | Description |
|---|---|
| Resume and LinkedIn makeover | ATS-friendly resume with before and after comparison |
| Mock interviews | Recorded sessions with written feedback |
| Placement Playbook | Mentors' real interview experiences |
| Communication workshops | Self-introduction, HR questions, group discussion basics |
| Accountability groups | Small peer groups that track each other |

## Mock Interview Rubric (Draft)

| Criterion | What is assessed | Scale |
|---|---|---|
| Technical depth | Correctness and clarity | 1 to 5 |
| Problem solving | Approach and reasoning | 1 to 5 |
| Communication | Structure and confidence | 1 to 5 |
| Project or subject ownership | Depth of understanding | 1 to 5 |
| Professionalism | Preparation and body language | 1 to 5 |

## Feedback Format

1. Strengths
2. Areas to improve
3. Specific next actions for the week
4. Rating per criterion

Groups of 4 to 5 students led by one mentor. Weekly check-in covers target completion, blockers and next week's commitments.
