## Asset Guidelines

1. **Strict Data Privacy:** Do not store student photos, interview recordings, or private personal information in this repository.
2. **File Naming Convention:** Use lowercase kebab-case for all files (e.g., `nms-logo-primary.svg`, `cert-template-v1.pdf`).
3. **Source Files:** Store editable source files (Figma links, SVG sources) alongside production exports.
